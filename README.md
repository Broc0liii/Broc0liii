### 📡 Radar & Focus

I am a software developer with a primary focus on **algorithms** and **computational optimization**. I enjoy diving into low-level mechanics, efficiency bottlenecks, and mathematical problem-solving.

* ⚡ **Algorithms & Optimization**: Deep interest in metaheuristics, nature-inspired optimization (such as *Particle Swarm Optimization* from scratch), and efficient data structures.
* ⚙️ **Low-Level Engineering**: Direct memory management, pointer arithmetic, and cache-conscious execution in **C**.
* 🌐 **Full-Stack Systems**: Architecting scalable backends with **ASP.NET Core Web API**, alongside reactive web applications in **Angular** and cross-platform clients in **.NET MAUI**.
* 🎯 **Engineering Mindset**: Profiling, algorithmic complexity analysis, and writing lean, high-throughput code.
